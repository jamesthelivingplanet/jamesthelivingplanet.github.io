# Archive Node

A personal blog built with Astro v5 — dark, minimal, and deliberately atmospheric.

The design mixes matklad's minimalist text-first approach with Bionicle's burnished gold aesthetic and Neon Genesis Evangelion's tactical interface language.

## Dev Commands

```bash
npm install       # Install dependencies
npm run dev       # Start dev server at localhost:4321
npm run build     # Build for production
```
